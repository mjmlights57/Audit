# EWPros v3.1.2 Upgrade

No new Supabase migration is required if v3.1.0 migration has already been run.

1. Back up or tag the currently working GitHub version.
2. Upload the complete v3.1.2 package contents to the GitHub repository, replacing the prior application files.
3. Let Netlify deploy the commit (or use **Clear cache and deploy site** if needed).
4. Confirm the sidebar shows **Administrator · v3.1.2**.
5. Test CRM Next Action/Due Date, project due-date ordering, archive/restore, collapsible Accounting/Banking sections, and the StrikeCheck CRM link.

### Project archive behavior
- Active projects are shown by default.
- Completed projects can be archived.
- Select **Archived projects** on the Projects page to view them.
- Click **Restore** to return an archived project to the completed-project list.

### CRM Next Action behavior
The CRM list uses the earliest open follow-up reminder for each customer:
- Reminder title → Next Action
- Reminder due date → Due Date

Add, complete, or delete reminders from the customer's **Activity** tab.
