# EWPros v3.1.0 Safe Upgrade

## Recommended test order

Keep the current Contabo VPS unchanged while testing v3.1.0.

1. Keep the known-good v3.0.4 ZIP as a rollback checkpoint.
2. Back up the Supabase database before changing the schema.
3. In Supabase SQL Editor, run `EWPROS-V3.1.0-MIGRATION.sql` once.
4. Upload the complete v3.1.0 project contents to the GitHub repository used by the Netlify test site.
5. In Netlify, use **Clear cache and deploy site** if necessary.
6. Confirm the Administrator header shows **v3.1.0**.
7. Test CRM before touching the VPS.

## CRM test checklist

### Customer import/export
1. Open **CRM**.
2. Create one test customer manually.
3. Click **Export all customers (CSV)** and confirm the file downloads.
4. Use `CRM-CUSTOMER-IMPORT-TEMPLATE.csv` or a small customer CSV.
5. Choose the default business line and stage.
6. Preview the file.
7. Verify the preview shows New / Duplicate / Error counts.
8. Import and confirm the customer appears once.
9. Import the same file again and confirm it is detected as a duplicate rather than creating another customer.

### CRM appointment flow
1. Open a CRM customer.
2. Under **Appointments**, click/expand **Schedule appointment**.
3. Select a date, business line and worker/auditor.
4. Leave **Show in Auditor Wizard** checked. EWPros requires an assigned worker before a CRM appointment can be sent to the field app.
5. Schedule the appointment.
6. Confirm it appears in the customer's appointment history.
7. Open **Appointments** in Admin and confirm it is shown as Source = CRM.
8. Open/synchronize Auditor Wizard and confirm the appointment appears with the same customer details and assigned auditor.
9. Cancel the test appointment from CRM and verify it remains in customer history but is no longer an active field visit.

### Projects
1. Open the same customer.
2. Create a test project from the CRM detail page.
3. Confirm the project appears under that customer and in the Projects module.

## Do not update the VPS yet

Only after the Netlify test site passes the v3.1.0 CRM, appointments, Auditor Wizard, Banking, Accounting, Team, Mileage, Invoice, PDF and existing utility-workbook checks should the same tested build be moved to Contabo.

The later VPS deployment should use the planned FileZilla/SFTP + versioned Docker image workflow with the current production image preserved for rollback.
