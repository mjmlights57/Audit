# EWPros v3.1.1 Upgrade

## If v3.1.0 Supabase migration was already run

No Supabase SQL is required for v3.1.1. This is an application/UI update.

1. Keep the current VPS untouched while testing.
2. Upload the complete v3.1.1 package contents to the GitHub repository.
3. Let Netlify deploy the new commit.
4. Use **Clear cache and deploy site** if Netlify/browser caching is suspected.
5. Confirm the admin sidebar shows **Administrator · v3.1.1**.
6. Open CRM and test Search, filters, New customer, Import, Export, opening a customer, Schedule, New Project, Edit, and Activity.
7. Confirm an appointment sent to Auditor Wizard still appears there.

## If v3.1.0 Supabase migration was NOT run

Run `EWPROS-V3.1.0-MIGRATION.sql` once before using the CRM-centered appointment features. v3.1.1 does not add another migration.

## VPS

Do not replace the current VPS container until this exact v3.1.1 build has been tested on Netlify.
