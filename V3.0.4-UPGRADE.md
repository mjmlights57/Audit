# EWPros v3.0.4 Upgrade

1. No new Supabase SQL is required if v3.0.3 is already installed.
2. Upload all v3.0.4 project files to GitHub, replacing the existing files.
3. Confirm GitHub contains `admin/business.js`, `admin/admin.css`, `admin.html`, and `admin/index.html` from v3.0.4.
4. Let Netlify deploy the commit. If needed, use **Trigger deploy → Clear cache and deploy site**.
5. Open `/admin.html` and confirm the sidebar header says `Administrator · v3.0.4`.
6. Banking test: choose an account and CSV file. The page should show `Selected: <filename>` and `Import transactions` must be clickable.
7. Team test: click `Remove` on a test worker. A white EWPros confirmation card should appear with `Cancel` and `Remove worker`; it should not appear as a browser error alert.
8. Test on Netlify before updating the VPS.
