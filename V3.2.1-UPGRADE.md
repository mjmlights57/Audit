# EWPros v3.2.1 Upgrade

This is an additive upgrade from EWPros v3.2.0. It does not delete existing CRM, project, banking, accounting, proposal, invoice, or audit data.

## Before deploying
1. Back up the Supabase database.
2. Confirm the corrected v3.2.0 migration has already completed successfully. If it has not, run `EWPROS-V3.2.0-MIGRATION.sql` from this package first.
3. In Supabase SQL Editor, run `EWPROS-V3.2.1-MIGRATION.sql`.
4. Upload the complete v3.2.1 package to GitHub and allow Netlify to deploy it.
5. Hard-refresh the administrator page and confirm it shows `Administrator · v3.2.1`.

## What the v3.2.1 migration adds
- `customers.utility`
- `customers.utility_account_number`
- `customers.business_type`
- `reminders.assigned_worker_id`
- `customer_documents` table for secure server-side CRM links to external document storage

## Quick verification
- CRM: `All Stages` should not show Inactive customers.
- CRM rows: earliest Next Action Due Date should appear first.
- New Customer: choose `Utility Programs`; Utility, Account #, and Business Type should appear.
- Customer → Activity: blue borders should be visible and an Assigned To selector should be available.
- CRM toolbar: `Assigned To` filter should list active Team members.
- Customer → Documents: add and open a test Google Drive/Dropbox/OneDrive link.

The Documents tab stores links only. It does not upload, copy, move, or delete files in Google Drive, Dropbox, OneDrive, or other storage services.
