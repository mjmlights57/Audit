# Deploy EWPros Auditor 2.8

1. Extract the full project ZIP.
2. Upload all extracted files and folders to the root of the GitHub repository.
3. Allow GitHub to replace existing files.
4. Commit the change.
5. In Netlify, use **Deploys → Trigger deploy → Clear cache and deploy site**.
6. Close and reopen the installed iPad PWA after deployment.
7. If an old version remains, remove the Home Screen PWA and reinstall it through Safari.

No new Netlify environment variables or Supabase tables are required.
