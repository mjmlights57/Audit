# EWPros v3.2.0 Upgrade

## Recommended order
1. Back up your Supabase database.
2. In Supabase SQL Editor, run `EWPROS-V3.2.0-MIGRATION.sql` once.
3. Upload the full v3.2.0 release contents to the GitHub repository used by Netlify.
4. Let Netlify deploy, or use **Clear cache and deploy site**.
5. Open `/admin.html` and confirm the sidebar says **Administrator · v3.2.0**.

## What to test first
1. CRM -> New Customer: confirm EWP/MJM Customer is required.
2. Create one EWPros test customer and one MJMLight test customer.
3. Open a customer and verify Customer Notes & Requirements is read-only until Edit.
4. Activity -> add two Next Action Tasks with different due dates. Complete the earlier one and confirm the next task moves into the CRM list's Next Action / Due Date.
5. Add/edit a Comment and confirm Latest Comment updates.
6. Click Proposal, edit scope/terms/line items and download PDF.
7. Click Invoice after saving a proposal and download PDF.
8. Audit Tools -> eSign should open https://ewpros.com/esign/index.php.
9. Open Notes, edit a line, Save notes, refresh, and confirm it persists.

## Existing customers
The migration assigns existing customers to EWPros so the new brand field has a safe value. If an existing customer belongs to MJMLight, open the customer -> Edit and change EWP/MJM Customer to MJMLight before creating proposals or invoices.

## Rollback
Keep your previous v3.1.4 release ZIP. The v3.2.0 database migration is additive; rolling the application code back does not require deleting the new tables/columns.
