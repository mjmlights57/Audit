# EWPros v3.0.2 Safe Upgrade

## Do not change Caddy, firewall, Docker networking, or Netlify while applying this release.

### 1. Back up the working deployment
Preserve the current working `ewpros` Docker image/container before switching production. The exact Docker commands should be chosen after confirming how the current VPS image was built.

### 2. Update Supabase first
In Supabase SQL Editor, run only:

`EWPROS-V3.0.2-MIGRATION.sql`

This migration adds void/undo tracking and bookkeeping categories. It does not delete existing customer/appointment tables.

### 3. Upload v3.0.2 source to a NEW VPS release directory
Use FileZilla/SFTP. Do not overwrite the currently working source directory until the VPS source/build path has been identified.

### 4. Build a NEW Docker image tag
Recommended pattern:

- current image: preserve as rollback
- new image: `ewpros:v3.0.2`

Do not remove the old image.

### 5. Test the new image before switching production
Test:
- Auditor login and appointment flow
- Admin login
- Add/delete a test bank account
- Add/delete a test transaction rule
- Preview a small CSV statement
- Confirm that Import transactions enables after preview
- Undo a test import
- Add/void a manual transaction
- Add/delete a vendor
- Add/delete mileage
- Add a custom accounting category

### 6. Switch production only after testing
Caddy should continue reverse-proxying the same host port. If the new release fails, restore the previous container/image.

## Important
The VPS/Netlify-independence question is intentionally not changed by this release. Verify it separately after v3.0.2 is stable.
