# Ctrl Qty and PEPCO Online Worksheet

## Auditor lighting rows

Interior and Exterior Lighting now use **Ctrl Qty** rather than Ctrl#. Enter the number of controls associated with the lighting line. Existing locally saved values from the former control-number field remain visible for migration and are exported as Control Quantity.

## Administrator: For_PEPCO_Online

The tab contains the 40 supplied online-portal fields. It is independent of the workbook and other admin tables.

Features:

- Official PEPCO and BGE portal links
- Editable section, instruction, and value columns
- Search
- Add, duplicate, and delete rows
- Save to the current browser
- Reset to supplied defaults
- Export as `EWPros_PEPCO_Online_Worksheet.csv`
- Application Date defaults to today
- Expected Completion Date defaults to two months from today

The default source data is also available in `PEPCO-Online-default.csv`.
