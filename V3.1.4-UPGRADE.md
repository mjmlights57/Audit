# EWPros v3.1.4 — Upgrade

1. Keep your existing Supabase database. **Do not run a new SQL migration for v3.1.4.**
2. Upload all v3.1.4 application files to the same GitHub repository used by Netlify, replacing the older application files.
3. Let Netlify complete the production deployment. If needed, use **Clear cache and deploy site**.
4. Open the administrator page and confirm the sidebar says **Administrator · v3.1.4**.
5. Test one customer that already has a project:
   - Open CRM and select the customer.
   - Under Overview → Customer notes, edit the notes and click **Save notes**.
   - Under Activity → Notes, add a new comment.
   - Confirm the new comment appears in the CRM list Notes column.
   - Edit that Activity comment and confirm the CRM list updates to the edited text.

This release does not require changes to Netlify environment variables, Supabase credentials, or the VPS.
