# EWPros v3.1.3 — Safe Upgrade

1. **Back up your Supabase database** (including customer, appointment, project, and accounting data). Make a copy/tag of the currently working v3.1.2 app so you can return to it if needed.
2. Open the included `EWPROS-V3.1.3-MIGRATION.sql` in a text editor. Copy only its SQL into your existing Supabase **SQL Editor**, then run it once. This installs the new permission-restricted, atomic deletion function; **running the SQL by itself deletes no projects**.
3. Upload all v3.1.3 application files to GitHub and let Netlify finish publishing. Confirm the header says **Administrator · v3.1.3**.
4. Open **Projects → Archived projects**. On a disposable archived test project, click **Permanently delete**, read the warning and type `DELETE`. Confirm the project disappears from both **Archived projects** and **All projects**. Refresh and verify it stays gone.
5. Check that its project-specific appointments, invoices, payments, time and mileage records are also gone. If the project had any imported bank transactions, check **Banking → Transaction review queue** for rows that need reclassification/reposting.

## Important
- The regular **Archive** and **Restore** controls have not changed.
- Deletion of invoices, income, expenses, or real employee payments may change prior-period reports or remove supporting records. Use permanent deletion for duplicate/test/error projects only unless the accounting implications are fully understood.
- Actual imported bank statement rows are retained for reconciliation and to prevent accidental re-import duplicates.
- The older client must not be used to permanently delete archived projects. A cached v3.1.2 page may still show the previous behavior; refresh after v3.1.3 has been published.
- This update changes only the application and adds one Supabase SQL function. It does not touch your Contabo VPS or Caddy configuration.
